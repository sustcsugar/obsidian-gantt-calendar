# Obsidian Gantt Calendar

[English](./README.md)

<div align="center" style="padding: 20px; border: 2px solid #8b5cf6; border-radius: 12px; background: linear-gradient(135deg, rgba(139, 92, 246, 0.05) 0%, rgba(59, 130, 246, 0.05) 100%); margin: 20px 0;">

一个强大的 Obsidian 任务管理和日历插件。

**多视图日历** — 任务视图/年/月/周/日/甘特图 六大视图自由切换

**节日显示** — 公历节日、农历节日、二十四节气

**数据可视化** — 任务热力图、每日任务数量统计、8 种渐变配色方案

**智能任务管理** — 全局筛选、优先级标记、6 种时间属性、时间精度 (HH:mm)、防行号漂移的安全写回

**连续时间画布** — 周/日/侧栏视图分钟级定位时间轴：点击创建、边缘拉伸（15 分钟吸附）、所见即所得拖放与落点预览

**移动端就绪** — 长按底部菜单、触屏拖动、滑动翻页、响应式布局

**Daily Note 集成** — 嵌入式编辑器，编辑/预览模式切换

**侧边栏视图** — 任务搜索筛选排序 + 每日时间线

**高度可定制** — 节日颜色、热力图配色、任务显示数量等全面配置

**双格式兼容** — 完美支持 Tasks 插件（emoji）与 Dataview 插件（字段）格式

**周期任务** — 支持 daily/weekly/monthly/yearly 重复任务，虚拟实例贯穿全部视图

**飞书同步** — 通过 OAuth 2.0 实现飞书任务双向同步

</div>

## 环境要求

| 项目 | 要求 |
|------|------|
| Obsidian | **1.13.0** 及以上 |
| 平台 | 桌面端 **与** 移动端均可（`isDesktopOnly: false`） |
| 可选 | [Tasks](https://github.com/obsidian-tasks-group/obsidian-tasks) 和/或 [Dataview](https://github.com/blacksmithgu/obsidian-dataview) —— 插件原生解析两种格式，**无需**安装它们 |
| 可选 | Obsidian 核心**日记**插件或 **Periodic Notes** 社区插件，用于日视图嵌入式编辑器 |
| 可选 | 飞书账号 + 自建飞书应用，用于任务同步 |

> 插件**只读写标准的 Markdown 任务行**。你的笔记始终是纯文本，卸载插件后笔记库完好无损。

## 安装

### 方式一 — 社区插件市场（推荐）

1. 打开 **设置 → 第三方插件 → 浏览**
2. 搜索 **Gantt Calendar**
3. 点击 **安装**，然后 **启用**

> 插件主页：<https://community.obsidian.md/plugins/gantt-calendar>

### 方式二 — BRAT（尝鲜最新提交）

1. 安装并启用社区插件 [BRAT](https://github.com/TfTHacker/obsidian42-brat)
2. 执行命令 `BRAT: Add a beta plugin for testing`
3. 填写仓库地址：
   `https://github.com/sustcsugar/obsidian-gantt-calendar`
4. 在 **设置 → 第三方插件** 中启用 **Gantt Calendar**

### 方式三 — 手动安装

1. 从最新的 [Release](https://github.com/sustcsugar/obsidian-gantt-calendar/releases) 下载 `main.js`、`manifest.json`、`styles.css` 三个文件
2. 创建文件夹 `<你的库>/.obsidian/plugins/gantt-calendar/`
3. 将三个文件复制进去 —— 文件夹名**必须**是 `gantt-calendar`
4. 重启 Obsidian，然后在 **设置 → 第三方插件** 中启用 **Gantt Calendar**

> 三个文件缺一不可。只复制 `main.js` 会导致插件无样式甚至无法加载。

### 更新

用当初安装的渠道重新安装即可。手动安装的话，覆盖三个文件后关闭再启用插件。`data.json` 中的设置会保留。

## 快速开始

### 1. 打开视图

三个等价入口：

- **侧边栏图标** — 点击左侧栏的 **甘特日历** 图标
- **命令面板** — `Gantt Calendar: 打开日历视图`（默认月视图）、`打开任务视图`、`打开侧边栏`
- **自动打开** — 启动时右侧栏会自动激活

用工具栏左侧的**视图切换**按钮在六大视图间切换。

#### 可用命令

| 命令 | 作用 |
|------|------|
| `Gantt Calendar: 打开日历视图` | 打开主视图并切换到**月视图** |
| `Gantt Calendar: 打开任务视图` | 打开主视图并切换到**任务视图** |
| `Gantt Calendar: 打开侧边栏` | 打开右侧栏视图 |
| `Gantt Calendar: 飞书任务双向同步` | 立即执行一次飞书同步 |

以上命令均可在命令面板中找到，并支持绑定快捷键。

### 2. 创建第一个任务

点击工具栏右上角的**添加任务**按钮（`+`）打开创建弹窗，或直接在任意 Markdown 文件中书写：

```markdown
- [ ] 🎯 完成项目文档 📅 2025-12-20
```

任务会立即出现在所有视图中，无需刷新。

### 3. 给它加上时间范围（可选但推荐）

同时有**开始**和**截止**日期的任务，会变成真正的甘特条和时间轴区块：

```markdown
- [ ] 🎯 完成项目文档 🛫 2025-12-10 📅 2025-12-20
```

把时间精确到分钟，任务就会落到时间轴画布上：

```markdown
- [ ] 🎯 每日站会 📅 2025-12-20 09:30
```

### 4. 试试这些交互

| 操作 | 位置 | 效果 |
|------|------|------|
| 拖拽任务卡片 | 月视图 / 周视图 | 在源文件中重新排期 |
| 点击空白画布 | 周 / 日 / 侧边栏 | 在该时刻创建任务（15 分钟吸附） |
| 拖拽区块上下边缘 | 周 / 日 / 侧边栏 | 调整开始/结束时间；按住 <kbd>Alt</kbd> 精调到 5 分钟 |
| 拖拽甘特条 / 端点 | 甘特视图 | 平移日期，或修改进度百分比 |
| 右键任意任务 | 所有视图 | 编辑 / 设置优先级 / 延期 / 取消 / 删除 |
| 点击任务 | 可配置 | 跳转到源文件，或弹出编辑面板 |

### 5. 接通日记（日视图）

启用 Obsidian 核心**日记**插件（或 **Periodic Notes**），然后打开 **设置 → Gantt Calendar → 日历**，开启**使用 Obsidian 日记设置**。日视图就会在任务时间轴旁内嵌加载当天日记。

也可以关闭该开关，手动设置文件夹 / 文件名格式 / 模板路径。

## 任务语法参考

### Tasks 插件格式（Emoji）

```markdown
- [ ] 🎯 完成项目文档 ⏫ ➕ 2025-01-10 🛫 2025-01-12 ⏳ 2025-01-14 📅 2025-01-15 #work
```

| Emoji | 含义 | Emoji | 含义 |
|-------|------|-------|------|
| `🎯` | 全局筛选标记 | `🔺` | 最高优先级 |
| `⏫` | 高优先级 | `🔼` | 中优先级 |
| `🔽` | 低优先级 | `⏬` | 最低优先级 |
| `➕` | 创建日期 | `🛫` | 开始日期 |
| `⏳` | 计划日期 | `📅` | 截止日期 |
| `✅` | 完成日期 | `❌` | 取消日期 |
| `🔁` | 重复任务 | `#tag` | 标签 |

### Dataview 插件格式（行内字段）

```markdown
- [ ] 🎯 完成项目文档 [priority:: high] [created:: 2025-01-10] [start:: 2025-01-12] [scheduled:: 2025-01-14] [due:: 2025-01-15] #work
```

| 字段 | 含义 | 字段 | 含义 |
|------|------|------|------|
| `priority::` | 优先级 | `created::` | 创建日期 |
| `start::` | 开始日期 | `scheduled::` | 计划日期 |
| `due::` | 截止日期 | `completion::` | 完成日期 |
| `cancelled::` | 取消日期 | `repeat::` | 重复规则 |

解析哪些格式可配置：**仅 Tasks**、**仅 Dataview**，或**两者都支持**（默认）。

### 时间精度

- 仅日期 — `YYYY-MM-DD`（如 `2026-04-27`）
- 日期 + 时间 — `YYYY-MM-DD HH:mm`（如 `2026-04-27 14:00`）

带时间的任务会在周 / 日 / 侧边栏时间轴上渲染为定位区块。仅日期任务、以及时长 ≥24 小时的任务，会落到**全天**行。

### 任务状态

复选框字符决定任务状态。内置状态：

| 符号 | 状态 | 符号 | 状态 |
|------|------|------|------|
| ` ` | 待办 | `x` / `X` | 已完成 |
| `!` | 重要 | `-` | 已取消 |
| `/` | 进行中 | `?` | 有疑问 |
| `>` | 已开始 | — | — |

可在 **设置 → Gantt Calendar → 任务 → 任务状态** 中添加自定义状态，每个状态都可配置独立的符号、颜色与描述。

### 周期任务

```markdown
- [ ] 🎯 周复盘 🔁 every week on Monday 📅 2026-01-05
- [ ] 🎯 交房租 🔁 every month on 1 📅 2026-01-01
- [ ] 🎯 浇花 🔁 every 3 days 📅 2026-01-05
- [ ] 🎯 换滤芯 🔁 every 6 months when done 📅 2026-01-05
```

| 规则片段 | 含义 |
|----------|------|
| `every day` | 每天 |
| `every 3 days` | 每 N 天 |
| `every week on Monday` | 每周指定星期几 |
| `every month on 15` | 每月 15 日 |
| `every year on 01-01` | 每年 1 月 1 日 |
| `every weekday` | 每个工作日（周一至周五） |
| `when done` | 下次日期从**完成当天**算起，而非原计划日期 |

插件会在年 / 月 / 周 / 日 / 任务 / 甘特图中渲染周期任务的**虚拟实例**。显示多少个未来实例由 **设置 → 任务 → 周期任务实例显示数量** 控制（设为 `0` 则关闭显示）。

> 编辑周期任务编辑的是**源行**。虚拟实例是只读投影；当你勾选完成某一次时，真正的实例由 Tasks 插件落地。

### 综合示例

```markdown
# 项目 Phoenix

- [ ] 🎯 启动会 🛫 2026-04-20 10:00 📅 2026-04-20 11:30 #会议
- [ ] 🎯 撰写技术方案 ⏫ 🛫 2026-04-21 📅 2026-04-28 #设计
- [ ] 🎯 干系人评审 🔼 🛫 2026-04-29 📅 2026-04-30 #评审
- [ ] 🎯 发布 v1.0 🔺 🛫 2026-05-01 📅 2026-05-15 #发布
- [ ] 🎯 周例会 🔁 every week on Friday 📅 2026-04-24 15:00 #会议
```

## 功能特性

### 界面布局

插件采用**顶部工具栏 + 内容区**的布局结构：

- **工具栏左侧** — 视图切换（6 个视图）
- **工具栏中间** — 当前日期范围 / 标题
- **工具栏右侧** — 功能按钮（排序、筛选、导航、添加任务、同步、刷新、设置）

### 年视图

- **全年概览** — 12 个月卡片展示全年任务分布
- **任务热力图** — 5 级颜色梯度，直观显示任务密度
  - 8 种配色方案：蓝 / 绿 / 红 / 紫 / 橙 / 青 / 粉 / 黄
  - 3D 热力图效果（关闭 / 轻微凸起 / 明显凸起）
- **响应式布局** — 根据窗口宽度自动切换 4×3 / 3×4 / 2×6 / 1×12 布局
- **任务数量统计** — 可选显示每日任务总数
- **农历显示** — 月卡片内显示农历日期
- **点击导航** — 点击日期切换到日视图

### 月视图

- **月度日历** — 标准月历布局，清晰显示每日任务
- **周数显示** — ISO 周数显示在每周第一列
- **任务数量限制** — 可配置每天显示任务数量（1–10），超出显示"+N 更多"
- **任务弹窗** — 点击日期显示当天完整任务列表
- **节日显示** — 阳历/农历/节气节日三色标记
- **拖拽排序** — 拖拽任务卡片在日期间移动
- **周期任务** — 自动显示重复任务的虚拟实例
- **周起始配置** — 支持周一/周日开始

### 周视图

- **连续时间画布** — 常驻 24 小时时间轴（不再有列表/时间轴模式切换）；任务块按分钟定位（1 小时 = 50px），带整点与半点网格线
- **智能任务块** — 区块按真实时长渲染：
  - 单一时间点的任务渲染为 1 小时点块，按字段角色锚定（开始类字段 → 向后 `[t, t+60)`，截止类字段 → 向前 `[t-60, t)`）
  - 同日区间按真实大小渲染；跨夜区间（<24h）跨列显示并带延续箭头
  - 跨天任务（≥24h）移到全天行显示为横跨条，并标注时间（`"22:00 → 18:00"`）
  - 文本在区块边界内自动折行（区块为主，文字为从）
- **全天行** — 仅日期任务 + ≥24h 横跨条，泳道行数不限，超过 3 行折叠为 `+N`
- **点击创建** — 点击画布空白处在该时刻创建任务（15 分钟吸附）；纵向拖拽可预选范围
- **边缘拉伸** — 拖拽区块上下边缘调整开始/结束（15 分钟吸附，Alt 精调到 5 分钟）；拉伸点任务会将其升级为区间任务
- **所见即所得拖放** — 落点锚定到区块边缘（而非光标）并显示落点预览；拖放点任务时会同时写入开始与结束
- **重叠泳道** — 最多 3 列并排；第 4 个起层叠显示带阴影
- **移动端** — 3 天滑动窗口，支持横向滑动
- **今日高亮** — 当天日期特殊标记；当前时刻指示线
- **农历信息** — 日期栏显示农历文本和节日

### 日视图

- **连续时间画布** — 与周视图相同的时间轴语义（分钟级定位区块、边缘拉伸、点击创建、落点预览、多行文本）
- **全天区** — 仅日期任务 + ≥24h 横跨条并带时间标注；拖到此处可转换为全天任务
- **拖拽交互** — 区块边缘锚定 + 落点预览；点任务拖放后升级为区间任务
- **当前时间指示线** — 红色线标记当前时刻
- **Daily Note 集成**
  - 嵌入式完整编辑器（WorkspaceSplit 模式）
  - 编辑 / 预览模式切换
  - 自动加载对应日期的 daily note
  - 支持 Obsidian 核心日记插件、Periodic Notes 插件和自定义路径
- **可调整分栏** — 任务区与笔记区之间可拖拽调整大小（水平或垂直布局）
- **农历信息栏** — 显示农历日期、节日、节气

### 任务视图

- **任务列表** — 集中展示所有任务
- **日期范围筛选** — 全部 / 今天 / 本周 / 本月 / 自定义范围
- **时间字段选择** — 按任意 6 种日期字段过滤
- **多维筛选** — 状态、优先级、标签（AND/OR/NOT 运算符）
- **排序** — 7 种排序字段，支持升序/降序切换
- **状态持久化** — 筛选和排序设置刷新后保留
- **周期任务** — 重复任务的虚拟实例会展开并按日期排序

### 甘特视图

- **交互式甘特条** — 自定义 SVG 渲染引擎
  - 拖动整体任务条调整时间
  - 拖动左右端点调整开始/结束时间
  - 拖动调整任务进度百分比
  - 点击打开任务编辑弹窗
- **导航按钮** — 跳转到今天 / 向左 / 向右滚动
- **增量刷新** — 基于指纹的差分（O(1) 事件）+ 拖拽即时写回（无延迟）
- **标签/状态筛选** — 按标签和任务状态过滤甘特条
- **可配置字段** — 选择映射到甘特图起止时间的日期字段
- **时间对齐** — 日粒度网格与日历视图语义一致；触屏友好手柄（22px 命中区）；条尾时间标注

### 侧边栏视图

两个标签页，方便随时查看和管理任务：

**任务列表标签页**
- 关键词搜索（防抖处理）
- 多维筛选：状态、优先级、标签（OR/AND）、日期范围
- 排序：优先级 / 截止日期 / 开始日期
- 点击任务卡片跳转到源文件或弹出编辑面板（设置 → 通用 → 点击任务卡片）

**每日时间线标签页**
- 24 小时时间格展示定时任务（默认今天）
- 标题行右侧导航切换日期（前一天 / 回到今天 / 后一天）
- 全天任务区域
- 当前时间指示线（实时标记）
- 拖拽任务调整时间
- 空时间格快速创建

### 右键菜单

右键点击任意任务可执行：

- **编辑任务** — 完整编辑弹窗（描述、优先级、日期、重复、标签）
- **创建笔记** — 从任务生成 wiki 链接笔记（同名或别名）
- **设置优先级** — 6 个等级：最高 / 高 / 中 / 普通 / 低 / 最低
- **设置状态** — 自定义状态（重要、有疑问）
- **延期任务** — 延迟 1/3/7 天（从截止日期或从今天算起）
- **取消 / 恢复** — 切换任务取消状态
- **删除** — 从 Markdown 文件中移除任务

### 飞书同步

- **双向同步** — 将本地任务推送到飞书，从飞书拉取任务到 Obsidian
- **OAuth 2.0** — 安全认证，自动刷新令牌
- **推送过滤** — 按文件路径、完成状态、日期筛选
- **冲突解决** — 多种策略：本地优先 / 远程优先 / 最新优先
- **自动同步** — 可配置自动同步间隔
- **同步结果弹窗** — 详细的逐任务同步结果和统计信息

> ⚠️ **启用同步前请务必备份笔记库。** 同步引擎仍在持续完善中，推送/拉取会直接写入你的 Markdown 文件。

<summary><b>飞书同步配置步骤（点击展开）</b></summary>

1. 在 <https://open.feishu.cn/app> 创建一个**自建应用**，记下 **App ID** 与 **App Secret**。
2. 在**权限管理**中开通以下权限：
   `offline_access`、`calendar:calendar:readonly`、`task:task:read`、`task:task:write`、`task:tasklist:read`、`task:tasklist:write`

5. 在 Obsidian 中打开 **设置 → Gantt Calendar → 同步**，填入 App ID / App Secret，点击**授权**，在浏览器中完成授权流程，然后把回调 URL 中的 `code` 参数粘贴回插件。
6. 点击**获取任务清单**，选择作为同步目标的任务清单。
7. 配置**同步方向**（双向 / 仅导入 / 仅导出）、**冲突解决策略**，以及可选的**自动同步间隔**（分钟；`0` 表示关闭）。

设置位于 **设置 → Gantt Calendar**，分为五个标签页。

### 通用

| 设置项 | 说明 |
|--------|------|
| 语言 | 跟随系统 / English / 中文 |
| 默认视图 | 打开插件时显示的视图（日/周/月/年/任务/甘特图） |
| 点击任务卡片 | 跳转到 Markdown 源文件，或弹出编辑面板 |
| 视图导航按钮显示文本 | 工具栏视图切换图标旁是否显示文字标签 |

| 时区 | 固定 UTC 偏移 —— 影响"今天"的判定与日历高亮（不自动处理夏令时） |

| 显示节日与节气 | 在农历文本上显示彩色高亮标记 |

|------|--------|
| 日视图 | 显示 Daily Note；布局 —— 左右分屏或上下分屏 |

## 常见问题与排查

**任务没有显示出来。**
1. 确认该行是真正的任务行：`- [ ]` 后面跟正文。
2. 如果配置了**全局筛选标记**，每个任务都必须带这个标记（`- [ ] 🎯 …`）。可在 **设置 → 任务 → 全局任务筛选标记** 修改或清空 —— 该项需要重启 Obsidian。
3. 检查启用的任务格式与你实际书写方式是否匹配（Tasks emoji vs Dataview 行内字段）。
4. 在日历视图中，任务按**日期筛选字段**定位 —— 没有该字段的任务自然无处显示。任务视图不受此限制，会显示全部任务。

**改了全局筛选标记却没生效。**
该项只在加载时读取一次。需要完全重启 Obsidian（仅关闭再启用插件不够）。

**在日历里拖拽任务，文件没变化。**
检查目标行在此期间是否被其他窗格编辑过 —— 插件检测到行号漂移时会拒绝写入，而不是破坏你的笔记。刷新视图后重试。

**甘特视图是空的。**
甘特起始/结束字段映射与你的任务不匹配。在 **设置 → 视图 → 甘特图** 中设置，例如起始 = `开始日期`，结束 = `截止日期`。

**周期任务显示了好多遍。**
那些是虚拟实例。调低或清零 **设置 → 任务 → 周期任务实例显示数量** 即可。

**农历日期不见了。**
当界面语言不是中文时，农历显示会被自动关闭；可在 **设置 → 日历** 中手动重新开启。

**日视图没有编辑器。**
要么启用 Obsidian 核心**日记**插件（或 **Periodic Notes**）并开启*使用 Obsidian 日记设置*，要么关掉该开关并手动填写文件夹与文件名格式。

**"今天"差了一个小时。**
时区设置是固定 UTC 偏移，不跟随夏令时。可以改为跟随系统，或选择无夏令时的地区。

**飞书同步提示需要授权 / 授权已失效。**
在 **设置 → 同步** 中重新授权。授权码约 5 分钟过期，请及时从回调 URL 复制 `code`。

**同步把我的笔记覆盖了。**
从备份或 Obsidian 的「文件恢复」核心插件中找回。使用同步前请务必先备份。

## 开发指南

### 前置要求

- Node.js 18+
- npm

### 初始化

```bash
git clone https://github.com/sustcsugar/obsidian-gantt-calendar.git
cd obsidian-gantt-calendar
npm install
```

> `npm install` 会执行 `postinstall`，删除 `obsidian-daily-notes-interface` 带进来的嵌套 `obsidian` 副本。这是预期行为。

### 脚本

| 命令 | 作用 |
|------|------|
| `npm run dev` | esbuild watch 构建 —— 保存即重新生成 `main.js` |
| `npm run build` | 类型检查（`tsc --noEmit`）+ 生产打包 |
| `npm run lint` | ESLint（`eslint-plugin-obsidianmd` 推荐配置） |
| `npm test` | Jest 测试套件（verbose） |
| `npm run test:watch` | Jest watch 模式 |
| `npm run bench` | 时间轴模型微基准测试 |
| `npm run version` | 通过 `version-bump.mjs` 升级 `manifest.json` + `versions.json` |

### 在真实笔记库中调试

把项目文件夹软链接或复制到 `<你的库>/.obsidian/plugins/gantt-calendar/`，运行 `npm run dev`，然后重载插件（`Ctrl/Cmd+P → 不保存重载应用`，或在设置中关闭再启用）。产物是单文件 CommonJS bundle `main.js`，`obsidian` 与 `electron` 保持外部依赖。

### 架构

```
main.ts                          插件入口 —— 视图、命令、设置面板、各管理器
src/
  GCMainView / GCSidebarView     Obsidian ItemView 挂载壳（React 挂载点）
  ui/
    App.tsx                      挂载 ModalProvider + TooltipProvider + 6 个视图
    views/                       年 / 月 / 周 / 日 / 任务 / 甘特图
    sidebar/                     SidebarApp + TaskListPanel + DailyTimelinePanel
    components/                  Icon、DropdownMenu、Modal、TooltipProvider、
                                 ContextMenu、TaskCard、Toolbar
    modals/                      TaskFormModal、ConfirmDialog、SyncResultDialog、
                                 modalHost（供非 React 环境调用的命令式桥接）
    store/calendarStore.ts       zustand store，承载视图状态与筛选
  data-layer/
    TaskStore                    供视图使用的门面
      ├── EventBus               发布-订阅
      ├── TaskRepository         内存 Map 缓存 + 文件索引
      │     └── MarkdownDataSource   库扫描（50 个一批，走 metadataCache）
      └── SyncManager（可选）     多源同步编排
  tasks/                         四步任务解析流水线 + 安全写回（防行号漂移）
  gantt/wrappers/                自定义 SVG 甘特渲染器
  settings/                      Builder 模式设置面板
  commands/                      命令注册（通用 / 条件 / 飞书）
  i18n/                          i18n 运行时 + en/zh 语言包 JSON
tests/                           Jest 测试（解析各步骤、行漂移、重复规则等）
```

**关键约定**

- DOM 类名走 `src/utils/bem.ts` 中的 BEM 常量 —— 禁止硬编码字符串
- 正则统一放在 `src/utils/RegularExpressions.ts` —— 禁止内联正则
- 悬浮提示复用 `src/utils/tooltipManager.ts` —— 禁止自行实现
- 任务修改走 `updateTaskProperties()` —— 禁止直接改写 Markdown 文本
- UI 一律声明式 React；基础组件、宿主与 Icon 封装之外禁止手写 `createEl` / `addEventListener`

## 贡献指南

欢迎各种形式的贡献 —— 缺陷报告、功能建议、翻译与代码。

### 报告缺陷与提需求

请到 [Issues](https://github.com/sustcsugar/obsidian-gantt-calendar/issues) 提交，并附上：

- Obsidian 版本、插件版本、操作系统，以及桌面端还是移动端
- 清晰的复现步骤
- 期望行为 vs. 实际行为
- 视觉问题请附截图或录屏
- 若涉及任务解析，请附上准确的 Markdown 任务行

提交前请先搜索是否已有同类 issue。

### 提交 Pull Request

1. **Fork** 仓库并创建主题分支：`git checkout -b fix/gantt-drag-jitter`
2. **保持改动聚焦** —— 一个 PR 只做一件事，避免顺带做无关的格式化
3. **遵守约定** —— 见上文[架构](#架构)一节：BEM 常量、共享正则、`updateTaskProperties()`、声明式 React
4. **补充测试** —— 解析器、日期工具、数据层改动请在 `tests/` 下补用例
5. **推送前验证** —— 以下三项必须全部通过：
   ```bash
   npm run lint
   npm run build
   npm test
   ```
6. **提交信息** —— 简短的祈使句标题，正文可选但需说明**为什么**。用 `#123` 关联 issue
7. **开 PR** —— 描述中说明：改了什么、为什么改、如何验证，以及 UI 截图
8. **及时响应评审** —— 维护者可能要求 rebase 或补充改动

> 本仓库自身的规则：**绝不自动 commit 或 push**，提交由作者自己决定。请保持分支历史干净，用 rebase 而不是 merge `master`。

### 参与翻译

界面文案位于 `src/i18n/locales/`。要新增语言，复制 `en.json`、翻译各值，并在 `src/i18n/i18n.ts` 中注册该语言。请保持键结构完全一致。

### 发布流程（维护者）

1. 升级三处版本号 —— `manifest.json`、`package.json`、`versions.json`（`"<版本>": "<最低 Obsidian 版本>"`）。`npm run version` 会处理 `manifest.json` + `versions.json`
2. `npm run build`
3. 提交，然后创建 **不带 `v` 前缀** 的 annotated tag（如 `1.6.3`）
4. 推送 `master` 与 tag
5. 创建 GitHub Release，附件固定为 `main.js`、`manifest.json`、`styles.css` 三个文件 —— 社区插件市场从这里拉取
